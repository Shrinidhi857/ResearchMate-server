## 📖 About The Project

**ResearchMate Server** is the backend powering the ResearchMate ecosystem. It provides a secure and scalable API for managing research projects, analyzing academic papers, and leveraging Generative AI to synthesize information.

Built with **Flask**, it integrates **Google's Gemini models** (`gemini-2.5-flash` and `gemini-embedding-2-preview`) and an advanced **RAPTOR (Recursive Abstractive Processing for Tree-Organized Retrieval)** RAG pipeline using **PGVector** (PostgreSQL vector extension) to deliver intelligent, context-aware answers from your uploaded documents.

---

## ✨ Key Features

- **🔐 Secure Authentication & RBAC**
  - **Google OAuth 2.0**: Seamless login with Google accounts.
  - **JWT Authentication**: Secure API session management.
  - **Role-Based Access Control**: Standard user and Admin (`@admin_required`) permission levels.

- **📚 Smart Document Management**
  - **PDF & Document Parsing**: Extract and process research documents cleanly.
  - **Vector Embeddings**: Automatic tree-structured vectorization using `gemini-embedding-2-preview`.
  - **Project Workspaces**: Group related research documents into dedicated project spaces.

- **🧠 Advanced RAG & RAPTOR Engine**
  - **RAPTOR Hierarchical Summarization**: Summarizes documents at multiple abstraction levels using UMAP dimensionality reduction and Gaussian Mixture Model (GMM) clustering.
  - **PGVector Permanent Storage**: Embeddings are stored natively in PostgreSQL collections (`raptor_<project_id>`) using `langchain-postgres`.
  - **Ephemeral Query Mode**: Run temporary direct text queries using in-memory **FAISS** vector stores without saving embeddings to the database.
  - **Contextual QA**: High-accuracy cited answers generated by `gemini-2.5-flash`.

- **🛡️ Admin Control & Token System**
  - **User Administration**: View, verify, grant/revoke admin rights, or delete accounts.
  - **Token Management**: Track, check, add, deduct, or set user token balances.
  - **Platform Analytics**: Operational summary reporting total users, documents, projects, and token consumption.

- **🛠️ Gemini-Powered LaTeX Agent**
  - **Agentic Assistant**: ReAct-based AI assistant powered by `GeminiLLM` for drafting and editing research papers in LaTeX format.
  - **WebSocket Live Feedback**: Streaming reasoning steps (`AGENT_THINKING`) and paper generation (`CODE_GENERATED`).
  - **Document-Aware**: Searches and reads project papers to inform citation and section writing.
  - **Targeted Edits**: Performs incremental modifications while preserving document structure.

## 🚀 Getting Started

Follow these steps to set up the backend locally.

### Prerequisites

- **Python 3.9+**
- **PostgreSQL 15+** with the **`pgvector`** extension enabled.
- **Google Gemini API Key** (obtain from [Google AI Studio](https://aistudio.google.com/)).

---

### 1. Clone the Repository

```bash
git clone https://github.com/Shrinidhi857/ResearchMate-server.git
cd ResearchMate-server
```

---

### 2. Set Up Virtual Environment

```bash
# Windows
python -m venv venv
venv\Scripts\activate

# macOS/Linux
python3 -m venv venv
source venv/bin/activate
```

---

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

---

### 4. Enable PGVector in PostgreSQL

Ensure your PostgreSQL database is running and install the `vector` extension:

```sql
CREATE EXTENSION IF NOT EXISTS vector;
```

---

### 5. Configure Environment Variables

Create a `.env` file in the root directory:

```bash
# Security
SECRET_KEY=your_super_secret_key
JWT_SECRET_KEY=your_jwt_secret_key

# Database Connection (PostgreSQL with pgvector)
DATABASE_URL=postgresql://postgres:password@localhost:5432/research_db

# Google OAuth 2.0
GOOGLE_CLIENT_ID=your_google_client_id
GOOGLE_CLIENT_SECRET=your_google_client_secret

# AI & Gemini Configuration
GEMINI_API_KEY=your_google_gemini_api_key
GEMINI_MODEL=gemini-2.5-flash

# Admin System
ADMIN_EMAIL=admin@example.com

# Frontend Integration
FRONTEND_URL=http://localhost:5173
```

---

### 6. Initialize Database Migrations

Run database migrations to initialize tables and schemas:

```bash
flask db upgrade
```

---

### 7. Run the Application

```bash
python run.py
```

_The Flask server will start at `http://localhost:5000`_

## 🧠 RAG, Retrieval Models & Vector Search Architecture

> [!NOTE]
> For complete mathematical formulations, code mappings, and algorithmic specifications, read the dedicated [RAG_AND_RETRIEVAL_ARCHITECTURE.md](file:///c:/code-2025/Research-Management/RAG_AND_RETRIEVAL_ARCHITECTURE.md).

ResearchMate implements a multi-tier hybrid retrieval architecture combining tree-organized hierarchical vector search, ephemeral in-memory indexes, ReAct tool-assisted agentic retrieval, and NLP relation extraction:

```
Upload Research Papers ──> Recursive Character Text Splitting (chunk_size=3500/2000)
                                      │
                                      ▼
                      UMAP Dimensionality Reduction (Cosine Metric)
                                      │
                                      ▼
                      Gaussian Mixture Model (GMM) Soft Clustering (BIC Selection)
                                      │
                                      ├──► Multi-Level LLM Summarization (gemini-2.5-flash)
                                      │
                                      └──► Dense Vector Embeddings (gemini-embedding-2-preview)
                                                 │
                                                 └──► PGVector Storage (raptor_<project_id>)
```

### Core Retrieval Engines & Models:

1. **RAPTOR Tree-Structured Vector Engine** ([`rag/raptor.py`](file:///c:/code-2025/Research-Management/rag/raptor.py)):
   - **Chunking**: `RecursiveCharacterTextSplitter` tokenized with `tiktoken` (`cl100k_base`).
   - **Embeddings**: `GoogleGenerativeAIEmbeddings` using `gemini-embedding-2-preview`.
   - **Dimensionality Reduction**: UMAP (`umap-learn`) using Cosine metric for global ($k = \lfloor \sqrt{N - 1} \rfloor$) and local ($k = 10$) feature space reduction to $d_{\text{red}} = 10$.
   - **Soft Clustering**: Gaussian Mixture Models (`sklearn.mixture.GaussianMixture`) minimizing Bayesian Information Criterion (BIC) for dynamic component count ($n \in [1, \min(50, N)]$) with soft assignment probability threshold $\tau = 0.1$.
   - **Summarization & Vector DB**: Multi-level tree construction recursively summarized via `gemini-2.5-flash` and stored in PostgreSQL using `langchain_postgres.vectorstores.PGVector`.

2. **Ephemeral In-Memory FAISS Engine** ([`temporary_query_pipeline`](file:///c:/code-2025/Research-Management/rag/raptor.py#L525)):
   - Zero-persistence, single-shot text retrieval using in-memory **FAISS** vector indexes (`langchain_community.vectorstores.FAISS`) for stateless context QA.

3. **ReAct Agentic Tool Retrieval** ([`app/codeagent/agent.py`](file:///c:/code-2025/Research-Management/app/codeagent/agent.py)):
   - Reasoning + Acting loop with structured JSON output (`AgentThought` / `ToolCall`).
   - Executes relational SQL pattern search (`search_docs`), primary-key payload reading (`read_doc`), and buffer inspection (`read_current_paper`) over WebSockets.

4. **Academic NLP & Graph Retrieval Engine** ([`service/analsys_control.py`](file:///c:/code-2025/Research-Management/service/analsys_control.py)):
   - Sentence intent semantic search ($\text{threshold} = 0.6$), weak supervision section classification, subject-predicate-object contradiction detection, and citation graph topology analysis using **NetworkX**.

## 🤖 Gemini LaTeX Agent

The **LaTeX Agent** is a standalone service powered by **Google Gemini** (`GeminiLLM`) running on a **Reasoning + Acting (ReAct)** loop.

### Conceptual Workflow:

1. **Thought**: Agent analyzes request and current paper state.
2. **Action**: Calls one of its tools:
   - `search_docs(query: str)`: Searches document keywords in project.
   - `read_doc(doc_id: str)`: Reads full text of a specific paper.
   - `read_current_paper()`: Inspects current LaTeX paper structure.
   - `none()`: Submits final generated LaTeX code.
3. **Observation**: Evaluates tool output and refines edits.
4. **Output**: Streams progress over WebSockets to the client.

### Running the LaTeX Agent Server

Open a separate terminal window and run:

```bash
python -m app.codeagent.routes
```

_The LaTeX Agent service listens on **port 8001** for WebSocket connections (`ws://0.0.0.0:8001/ws/{client_id}/{project_id}`)._

## 📌 API Reference

### 🔐 Authentication (`/auth`)

| Method | Endpoint               | Description                             |
| ------ | ---------------------- | --------------------------------------- |
| `POST` | `/auth/google`         | Google OAuth authentication             |
| `GET`  | `/auth/login`          | Initiate OAuth redirect                 |
| `GET`  | `/auth/callback`       | OAuth callback handling                 |

### 👤 User & Tokens (`/users`)

| Method | Endpoint               | Description                             |
| ------ | ---------------------- | --------------------------------------- |
| `GET`  | `/users/user`          | Get user profile & token count          |
| `GET`  | `/users/tokens`        | Get token balance                       |
| `POST` | `/users/tokens/check`  | Check if user has required token balance|

### 📁 Projects & RAG (`/projects`)

| Method | Endpoint                             | Description                             |
| ------ | ------------------------------------ | --------------------------------------- |
| `GET`  | `/projects`                          | List user projects                      |
| `POST` | `/projects`                          | Create a new project workspace          |
| `POST` | `/projects/<id>/build-context`       | Build RAPTOR tree & store in PGVector   |
| `POST` | `/projects/<id>/ask`                 | Ask RAG question using Gemini           |

### 📑 Document Analysis (`/analyse`)

| Method | Endpoint                                  | Description                         |
| ------ | ----------------------------------------- | ----------------------------------- |
| `GET`  | `/analyse/stream-analysis/<session_id>`   | Stream paper summary via Gemini SSE |

### 🛡️ Admin Management (`/admin`)

| Method   | Endpoint                          | Description                             |
| -------- | --------------------------------- | --------------------------------------- |
| `GET`    | `/admin/users`                    | List all registered users (paginated)   |
| `GET`    | `/admin/users/<id>`               | Detailed user information               |
| `POST`   | `/admin/users/<id>/verify`        | Verify user account                     |
| `POST`   | `/admin/users/<id>/grant-admin`   | Grant admin privileges                  |
| `POST`   | `/admin/users/<id>/revoke-admin`  | Revoke admin privileges                 |
| `DELETE` | `/admin/users/<id>/delete`        | Delete user account                     |
| `POST`   | `/admin/users/<id>/tokens/add`    | Add tokens to user balance              |
| `POST`   | `/admin/users/<id>/tokens/deduct` | Deduct tokens from user balance         |
| `POST`   | `/admin/users/<id>/tokens/set`    | Explicitly set token balance            |
| `GET`    | `/admin/analytics`                | Platform statistics overview            |
| `GET`    | `/admin/token-usage-report`       | Detailed token usage report             |
